# 首批题库资源交接说明

这个目录用于放置待审计的题库、教案、试卷和模板。第一批不需要一次性上传全部资源，建议先提供 100—300 道具有代表性的题，或 5—10 个原始文件。

## 可以直接提供的格式

- DOCX
- PDF
- XLSX、CSV
- JSON
- PNG、JPG 等扫描图片
- Markdown、TXT

不需要先完成 OCR、公式清洗或统一排版。保留原始文件通常更有利于追溯。

## 请同时提供的信息

在文件名、同目录说明文档或单独表格中尽量说明：

1. 资源来自哪里。
2. 是本人原创、购买、学校内部积累，还是网络收集。
3. 是否存在合同、发票、授权书或平台使用协议。
4. 是否允许商业展示。
5. 是否允许修改和生成变式题。
6. 是否允许用于模型微调。
7. 是否包含教材、教辅或试卷扫描图片。
8. 是否允许提供给同校教师或所有付费用户。

不确定的项目可以填写“未知”，不要猜测。

## 首批审计将输出

- 文件清单和格式统计。
- 题目数量估算。
- OCR 与公式质量抽样。
- 重复题比例抽样。
- 题干、答案、解析完整率。
- 人教 A 版知识点映射样例。
- 内容来源和商业使用风险分级。
- 建议进入公共库、私有库或研究区的范围。

## 安全与版权提醒

- 不要上传真实学生姓名、联系方式、成绩单等个人信息。
- 如果资源权利状态不明确，可以上传少量样本用于结构审计，但不会默认进入商业公共题库或模型训练。
- 原始文件不会因放入本目录就自动获得公共展示或训练授权。
