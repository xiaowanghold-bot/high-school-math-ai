## 第 1 题冲突说明

题目给出 `f(3+x)=f(1-x)`，可推出 `f(t)=f(4-t)`，因此函数图象关于 `x=2` 对称，并有 `f(1)=f(3)`。又因为 `3,4∈(2,+∞)` 且函数在该开区间严格递减，所以只能确定 `f(4)<f(1)=f(3)`。

条件没有约束端点 `x=2` 的函数值，`f(2)` 可以改变而不破坏其余条件，因此不能确定 `f(1)、f(2)、f(4)` 的完整大小次序，四个选项都不是必然结论。来源给出的 A 不能由题面推出。

可改编方案：把单调区间改为 `[2,+∞)`，或另加 `f(2)>f(1)`。采用前者后可得到 `f(4)<f(1)<f(2)`，即选项 A。改编仍需教师确认。
