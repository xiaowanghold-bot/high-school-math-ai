# 教师／管理员工作模式 v1

## 目标

首版由同一项目所有者兼任数学教师和平台管理员。工作模式切换用于减少无关入口、区分教学任务与内容治理任务，并为后续真实账户权限保留清晰的代码接缝。

## 身份模块

`RoleProvider` 是前端唯一的身份状态模块，对调用方只提供：

- 当前角色 `teacher / admin`；
- 是否已经读取本地状态；
- 当前角色对应的操作人 ID；
- 切换角色的方法。

角色保存在浏览器本地存储和同站 Cookie 中。侧栏导航、顶部任务与快捷操作、管理页门禁都从该模块读取状态，不在各页面重复实现角色判断。

## 模式能力

教师模式：

- 教材备课、搜题、解题；
- 创建和导出教案；
- 创建和导出试卷；
- 管理个人资料。

管理员模式：

- 查看管理总览；
- 处理题库内容和数学核验任务；
- 审核教材目录；
- 管理私人资料；
- 进入批量 PDF 内容生产流程。

`/admin`、`/curriculum/review` 和 `/imports` 使用统一 `AdminGuard`。教师模式直接访问时不会加载管理工作区，而是显示身份说明和显式切换按钮。

## 安全范围

当前版本是单人自用阶段的“工作模式”，不是正式认证系统。浏览器本地状态不能替代服务端身份验证，也不能作为商业环境中的安全凭证。

商业上线前必须继续完成：

1. 账号登录、会话和密码／第三方身份验证；
2. 服务端 RBAC 权限校验，所有写接口以服务端会话为准；
3. 用户、组织、套餐和管理员授权数据模型；
4. 角色切换与高风险操作审计；
5. 越权访问和会话失效自动测试。
