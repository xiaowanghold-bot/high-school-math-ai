# 批量 PDF 加工中心 v1

## 目标

把来源可追溯的多份 PDF 登记为加工批次，保留不可变原文件，并生成逐页文字层、题号标记和内嵌图片统计，为后续题目边界、小问、公式与配图校对提供可靠底座。

本阶段不创建题库题目，也不把“已分析”等同于“可公开发布”。

## 模块与接口

`PdfImportStudio` 是批量加工的深模块，接口包含：

- `create_batch`：验证权利声明、PDF 格式、大小、页数和重复内容，原子化登记一批文件。
- `workspace`：返回批次、文件和整体处理指标。
- `inspect`：返回一个文件及其逐页分析结果。
- `analyze` / `analyze_batch`：可重复执行逐页分析，并返回最新结果。

模块内部隐藏 SQLite 表、文件命名、哈希去重、pypdf、题号识别和失败状态更新。HTTP 路由只负责 multipart 输入与错误映射，页面不直接拼装加工状态。

页面预览由 PDFium 在后端按需渲染为 PNG，并按文件、页码和宽度缓存。这样不依赖浏览器原生 PDF 插件，也为下一阶段的坐标框选与图片裁剪提供稳定像素坐标。

## 数据对象

- `import_batches`：批次名称、权利依据、使用边界、所有者和时间。
- `import_files`：原文件名、不可变哈希、受控存储名、页数、处理状态和汇总指标。
- `import_pages`：页码、页面尺寸、提取文字、文字层状态、题号标记、内嵌图片数量和警告。

原始 PDF 存放于 `data/runtime/pdf-import-files`，不纳入 Git。数据库位于 `data/runtime/pdf-imports.sqlite3`。

## 门禁

- 未确认来源与使用权声明时不能登记。
- 只接受真实 PDF；扩展名正确但内容不是 PDF 时拒绝。
- 加密、空页、超过 1200 页、单份超过 100 MB 的文件拒绝。
- 单批最多 12 份、总量最多 350 MB。
- SHA-256 完全重复的文件不能二次登记。
- 页面分析只生成加工元数据，不生成题库候选。

## 页面分析语义

- 每页提取文字、字符数、页面尺寸和稳定题号标记数量。
- 少于 20 个字符的页面标记为文字层不足，进入 OCR 或人工转录队列。
- 记录每页内嵌图片数量，为几何图、统计图和表格裁剪提供入口。
- 题号标记只是边界候选，不能替代教师确认；答案区、讲义例题和页码均可能造成假阳性。
- 分析可重复执行；旧页面结果由同一文件的新分析原子替换。

## 真实样本验证

使用 7 页《圆交线、圆切线的最值分析》进行只读验证：

- 7 页均有可提取文字层，共 4166 个字符。
- 识别到 27 个题号标记，与既有审计估计一致。
- 7 页包含 12 个内嵌图片对象。
- 代表页面经 Poppler 渲染检查，公式、圆图、选项和答案区域清晰可见。

## 下一阶段

在 `import_pages` 之上增加题目区域候选与校对界面：

1. 用页码和坐标保存题干、选项、答案、解析区域。
2. 支持复合题小问拆分和学生版/解析版配对。
3. 裁剪原图作为私人加工证据，并支持替换为自有重绘图。
4. 对公式生成 LaTeX 候选和渲染预览。
5. 教师确认后才写入现有题库审核流程。
