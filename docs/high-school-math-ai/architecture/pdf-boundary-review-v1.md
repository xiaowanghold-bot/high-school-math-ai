# PDF 题目边界校对台 v1

## 目标

将逐页分析得到的题号标记转换为教师可审核的题目边界候选。候选仅存在于 PDF 加工区，不会自动写入正式题库。

## 核心边界

`PdfImportStudio` 继续作为 PDF 加工深模块，对外只暴露以下教师工作流：

1. 从已完成逐页分析的文件生成候选；
2. 查看候选及待校对、已确认、已弃用数量；
3. 修改起止页、题型、小问数量、原始连续内容和备注；
4. 手工补充自动规则遗漏的题目；
5. 确认或弃用候选。

自动提议具有幂等保护：文件一旦存在候选，再次请求不会覆盖教师修改。重新分析 PDF 后，候选仍保留原分析时间戳，后续版本可据此增加“来源已更新”提醒。

## 数据模型

`import_boundary_candidates` 保存：

- 原文件与来源分析时间；
- 候选顺序、起止页和文字偏移；
- 原始连续内容；
- 题型、小问数量；
- `draft / confirmed / discarded` 审核状态；
- 教师备注、编辑者与更新时间。

当前版本保留题目、解析和讲义提示等连续内容。下一加工环节再进行题干、选项、解析、公式和图片的结构化拆分，避免在边界尚未确认时过早丢失原始信息。

## 自动边界规则

- 支持行首数字题号、`【例/题 N】`、`第 N 题` 和模拟题来源格式；
- 同一页相邻题号之间形成一个候选；
- 后续页面没有新题号时，自动续接到上一候选，支持跨页题；
- 自动推断解答题、填空题、选择题和小问数量，但均可由教师覆盖；
- 扫描页或不稳定版式允许教师手工补题。

## 安全门

“确认边界”只表示教师完成了范围校对。正式入库前仍需经过公式规范化、选项拆分、图片归属、题干与解析分离、去重和最终审核。
