# 私人资料拆题流水线 v1

## 目标

把教师已经校对确认的私人资料文字，转换为可逐题编辑、可追溯、默认不可发布的题库草稿。原文件、OCR 文本、拆题候选和题库题目保持分层，任何一步都不能绕过下一层审核。

## 模块边界

`PrivateLibrary` 负责文件校验、原文提取、OCR 授权记录、教师文本版本和拆题候选；`QuestionBank` 负责题目草稿、配图、数学验证、教师审核和发布门禁。HTTP 路由只编排两个模块，不直接写数据库。

稳定流程：

`上传 → 教师校对确认 → 本地确定性拆题 → 逐题编辑 → 导入私人题库 → 独立数学核验 → 教师审核`

## 关键约束

- 未确认文本不能拆题。
- OCR 每次调用都要求教师明确同意外部处理；未配置服务时保留人工转录路径。
- OCR 输出自动回到 `pending`，不能自动确认。
- 拆题候选按资料文本版本隔离；教师修改文本后生成新版本候选。
- 候选导入采用确定性题号，重复请求不会创建重复题目。
- 导入题始终是 `private`、`pending`、`needs_math_review`。
- 私人教学资料的商业权利保持阻断；原创或已授权声明仍保留来源记录并接受正常发布门禁。
- 图片型原题导入时复制到题库受控媒体目录，使用固定尺寸元数据与题干位置；后续可在题库审核台替换、排序或删除。

## OCR 数据边界

OpenAI 适配器通过 Responses API 发送图片或文件输入，要求结构化返回转录文本与警告，并设置 `store: false`。这只约束本应用的请求方式，不替代教师对第三方服务数据政策的判断；界面必须在调用前说明本次会发送原文件。
