# V1 信息架构与核心页面流程 v0.1

## 1. 设计目标

教师进入任一核心任务后，三次主要点击内到达可操作内容。界面优先适配 13 至 16 英寸电脑，同时保证平板横屏可用。首版不把手机作为重度教案编辑设备，但支持查看、收藏和简单搜索。

## 2. 全局导航

### 一级导航

1. 工作台
2. 教材备课
3. 智能搜题
4. 教案
5. 组卷
6. 我的资料

### 全局操作

- 顶部统一搜索框
- `+ 新建`：教案、试卷、上传资料
- AI 任务中心
- 收藏夹
- 使用额度
- 账户与设置
- 管理后台入口（仅管理员可见）

## 4. 核心流程

### 4.1 教材备课

`工作台 → 教材章节 → 知识点备课页 → 新建教案 → AI初稿 → 分块编辑 → 插入/替换题目 → 教师确认 → 导出`

### 4.2 智能搜题

`搜索描述 → 系统解析条件 → 混合检索 → 权利过滤 → 查看题目 → 收藏/加入教案/加入试卷`

搜索结果采用双栏布局：左侧为筛选器和结果，右侧为题目快速预览，减少频繁跳页。

### 4.3 题目生成

`选择知识点或参考题 → 指定变式目标 → 生成结构化题目 → 数学验证 → 风险提示 → 教师修改确认 → 保存`

### 4.4 组卷

`设置总分与结构 → 手选或自动选题 → 难度/知识点检查 → 调整顺序和分值 → 预览学生卷与答案卷 → 导出`

### 4.5 私人资料导入

`上传文件 → 权利声明 → 后台解析 → 题目切分 → 公式/图片校对 → 私有题库 → 可选教师确认`

## 5. 关键页面布局

### 5.1 教案编辑器

- 左栏：教案结构目录。
- 中栏：分块内容编辑区。
- 右栏：AI操作、引用题目、来源和版本记录。
- 顶栏：保存状态、预览、导出和教师确认。

每个内容块只有四个主要操作：编辑、锁定、AI重写、更多。锁定块不会被整篇重新生成覆盖。

### 5.2 题目详情

- 主区：题干、图形、选项、小问。
- 解析区：答案、分步解析、第二解法、易错点。
- 侧栏：教材位置、题型、难度、来源、权利状态、验证记录。
- 底部操作：收藏、生成变式、加入教案、加入试卷、报告问题。

### 5.3 内容审核

- 左栏：待审队列和风险筛选。
- 中栏：原题页与标准化题目对照。
- 右栏：公式、答案、知识点、来源和发布门禁。
- 快捷键：通过、退回、下一题。

## 6. 视觉设计方向

- 风格：克制、专业、纸张感轻量化，不采用娱乐化教育风格。
- 主色：深靛蓝，用于导航和主要按钮。
- 强调色：青绿色，用于“已验证”和成功状态。
- 警告色：琥珀色；错误和权利阻断使用红色。
- 背景：浅灰白；编辑内容使用白色卡片。
- 数学正文优先使用清晰宋体/衬线字体，操作界面使用无衬线字体。
- 题目正文最小字号不低于 16px，行高不低于 1.65。
- 所有状态同时使用文字和颜色，不只依赖颜色区分。

## 7. V1 不进入导航的功能

- 学生端和作业发布。
- 学校组织管理。
- 社区、评论和公开分享广场。
- 自动批改和学生成绩分析。
- 原生移动 App 专属功能。

5. 教案编辑器。
